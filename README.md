# ari. — Your AI Data Analyst

ari. is an AI-powered data analysis web app designed to make business analytics feel like a real conversation with a human data analyst.

Users can upload CSV or Excel files, explore interactive insights, and chat with ARI to understand trends, products, customers, revenue performance, and business opportunities through a clean and minimal interface.

## Features

- AI-powered conversational analytics
- CSV/XLSX upload and automatic analysis
- Interactive charts and business insights
- AI chat assistant for dataset-specific questions
- Geographic analysis and maps
- Bilingual support (Italian & English)
- Minimal modern UI inspired by Apple and SaaS products

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- OpenAI API
- Geopy

## Vision

ari. aims to transform data analysis into a more human, intuitive, and accessible experience by combining AI, analytics, and conversational interaction into a single platform.
